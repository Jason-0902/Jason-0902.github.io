About me

I am a computer science graduate from Chung Yuan Christian University in Taiwan, with a strong interest in systems security, software security, and vulnerability research.

My undergraduate research focused on exploring fuzz testing techniques for Autoware, an open-source autonomous driving software platform built on ROS 2. Through this project, I gained practical experience with fuzzing frameworks, memory error detection, API analysis, and the challenges of testing complex software systems.

Beyond academic research, I continue to develop my technical skills through security challenges, reverse engineering exercises, systems programming, and personal software projects.

I am particularly interested in understanding how software fails, identifying security weaknesses, and developing tools to improve software reliability and security.
